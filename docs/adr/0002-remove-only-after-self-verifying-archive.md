# 移除原文件以自校验归档包为前提，不设宽限期

移除是不可逆的，而任何宽限期都会抵消产品目的——隔离中的原件仍在同一块盘上，宽限期内一点空间都没释放。因此决定：保持「校验通过即移除」为默认，但删除的前置条件从「存在且大小一致」升级为**自校验归档包**——校验和与数据一起存放在 zip 内部，归档包设为只读，启动检查之外提供用户可触发的完整校验。

**Context**：PRD §5.7 原定的轻量启动检查（大小与清单一致）已被实测证伪——删掉 zip 中某条目的数据后，`unzip -l` 仍会打印完整健康的条目列表。大小一致不能证明数据在场，完整性必须走内容（sha256）校验，且清单绝不能从 `unzip -l` 读取，那是唯一被证明会骗人的接口。

**Consequences**：

- 「随机访问」仅指包完整在场时取单条目（已实测到 5.6 GB 逐字节一致）；中央目录在文件末尾，截掉尾部则全部条目不可访问。不得向用户承诺部分可用或损坏恢复。
- 界面上「已归档」与「已移除」是两个独立状态，不互相隐含。
